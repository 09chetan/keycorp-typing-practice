📋 3-Step 1-Minute Setup Guide for Your Sheet
  1. Open your spreadsheet: Click here to open Sheet ↗
  2. In the top menu, click Extensions ➔ Apps Script.
  3. Delete any code in the editor, paste this exact snippet, and click Save (Ctrl+S):
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); if (sheet.getLastRow() === 0) { sheet.appendRow(["Date", "Time", "Category", "Mode", "Duration", "WPM", "Net WPM", "Accuracy", "Words Typed", "Errors", "Misspelled Words", "Session Paragraph"]); } sheet.appendRow([data.date, data.time, data.category, data.mode, data.duration, data.wpm, data.netWpm, data.accuracy, data.wordsTyped, data.errors, data.misspelledWords, data.sessionText]); return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON); }
  1. Click Deploy (blue button at top right) ➔ New deployment.
  2. Click the gear icon ⚙️ next to 'Select type' ➔ choose Web app.
  3. Set Execute as: Me and Who has access: Anyone.
  4. Click Deploy (grant access if prompted), then Copy the Web app URL and paste it into the field above!
